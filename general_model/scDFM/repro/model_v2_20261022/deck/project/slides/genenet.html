從沒被實驗測過的基因：GeneNet4

如果某個基因從來沒被任何實驗關掉過，就沒有「來源」可以參考。

GeneNet4 改找功能最像的 32 個基因（STRING 蛋白網路 + GO 功能註解），用它們被關掉時的反應來推測，並學會該相信多少。

期末考的 300 個基因都有測量資料，所以期末主要靠 AdaptNet；GeneNet4 讓模型能處理「任何基因」。

通用模型還要能處理「從來沒被實驗關掉過的基因」。這種基因沒有任何來源資料，所以我們做了 GeneNet4：它會從 STRING 蛋白交互網路和 Gene Ontology 功能註解，找出功能最像的 32 個基因，拿它們被關掉時的反應來推測，並且學會這種推測要相信多少。右邊是驗證結果：有測量資料的基因，在沒看過的細胞上方向相似度約 0.15；完全沒測量的基因，再加上沒看過的細胞，只有 0.025。這是我們試過的方法裡最好的，但訊號很弱，代表只靠基因知識很難預測。期末考的 300 個基因都有測量資料，所以期末主要靠 AdaptNet。
